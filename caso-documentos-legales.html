Documentos legales URGENTE
y documentos constituyentes

Cómo un equipo de 4 personas puede ponerse de acuerdo, revisar y firmar documentos críticos sin caer en el caos de versiones por email o WhatsApp.

📋 El problema que tenemos ahora

Situación actual:

  • Documento A (urgente): Texto legal que debe ser revisado y firmado por todos en menos de 48 horas. Cualquier retraso tiene consecuencias.
  • Documento B (importante): Documento constituyente que define las bases del grupo. No es urgente en días, pero es crítico para la organización futura.
  • El problema común a ambos: Cada persona tiene sus cambios en su versión local. Los comentarios llegan por WhatsApp, emails, o llamadas. Nadie tiene la "versión definitiva" clara. Se pierden sugerencias. Alguien dice "yo ya lo corregí" y otro dice "esa no es la última versión".

"¿Esto también lo resuelve IgnisBrain?". Si, es exactamente el caso de uso para el que fue diseñado.

⚡ Dos enfoques posibles

Dependiendo de la urgencia y los recursos del equipo, IgnisBrain ofrece dos caminos. Ambos comparten la misma base: un único archivo de consenso como fuente de verdad.

🤖⚡
Con IA · Para lo URGENTE

48 horas · Firmas inmediatas

Ideal para el documento legal urgente. Usamos IA para acelerar la consolidación de cambios y generar el documento final.

Flujo de trabajo:

  1. 1. Subir la versión base → Alguien sube el borrador inicial a public/borradores/documento_legal_v0.md.
  2. 2. Cada uno comenta en actas → En lugar de emails, cada persona crea un archivo en public/actas/ con sus correcciones y observaciones.
  3. 3. Asistente Ignis (IA) consolida → Se le pide: "Ignis, lee el borrador y las 4 actas de comentarios. Genera una versión consolidada con las sugerencias que coinciden y marca las contradicciones."
  4. 4. Resolución rápida de contradicciones → Solo las discrepancias reales se discuten (en lugar de las 50 correcciones menores).
  5. 5. Generación del documento final → El script md2html.py o md2pdf.py genera el documento listo para firmar.
# Ejemplo de prompt para Ignis "Ignis, tengo el documento base en public/borradores/contrato_v0.md y cuatro actas en public/actas/ con comentarios de Juan, Ana, Luis y yo. Genera un documento consolidado. Cuando encuentres una contradicción (ej: Juan dice 'plazo 15 días' y Ana dice 'plazo 30 días'), marcala con [CONTRADICCIÓN] y dime quiénes discrepan."

Tiempo estimado: 2-4 horas de trabajo efectivo + 24h para firmas.

📝🐢
Sin IA · Para lo IMPORTANTE

Documento constituyente · Con calma

Para el documento que define las bases del grupo. No es urgente, pero debe ser reflexivo y consensuado. Sin prisas, sin IA.

Flujo de trabajo:

  1. 1. Versión base → Borrador en public/borradores/constituyente_v0.md.
  2. 2. Revisión asíncrona → Cada uno crea un acta con sus propuestas. No se edita el borrador directamente (evita conflictos de Git).
  3. 3. Consolidación manual → Una persona (o rotativa) integra las propuestas en una nueva versión (v1, v2...).
  4. 4. Ronda de validación → Se sube la versión consolidada y se abre un período de "objeción" (ej: 48h).
  5. 5. Acta de cierre → Una vez sin objeciones, se documenta en public/actas/ que el documento constituyente queda aprobado.

Ventaja clave: Todo el historial de versiones y discusiones queda guardado en Git. Dentro de un año, si alguien pregunta "¿por qué se incluyó esta cláusula?", la respuesta está en un acta.

🔧 La solución técnica (sin humo)

Esto no requiere instalar nada complejo. Solo:

  • Git (lo usan los programadores, pero se aprende en 10 minutos)
  • Una cuenta gratuita en GitHub o GitLab
  • Opcional para IA: Ollama (local y gratis) o una API de ChatGPT

Lo más importante que este sistema resuelve:

El problema no es técnico. Es humano: "¿cuál es la última versión?", "¿dónde estaba ese comentario?", "¿quién dijo qué?". IgnisBrain no es magia. Es un lugar único y ordenado para que el desacuerdo y el acuerdo convivan documentados. La IA solo acelera la consolidación. El valor real está en saber que todo lo que se dijo está en un archivo, no en una conversación perdida.

🎯 "El problema de ponerse de acuerdo no es técnico. Es humano."

IgnisBrain no elimina las discusiones. Las organiza para que se resuelvan en lugar de perderse.
